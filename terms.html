2. Политика конфиденциальности и Федеральный закон № 152-ФЗ

2.1. Отсутствие слежки и кейлоггеров: Программа RusEn не содержит шпионских модулей (spyware, keyloggers) и скрытых средств сбора информации. Нажатия клавиш обрабатываются локально исключительно в оперативной памяти компьютера пользователя в режиме реального времени для определения языка и автоматического исправления ошибок ввода. Вводимый текст никуда не сохраняется и не передается по сети.

2.2. Голосовой ввод: Запись аудиопотока с микрофона активируется исключительно вручную пользователем (при удержании клавиши Shift или нажатии F8). Аудиоданные передаются по зашифрованному каналу HTTPS/TLS напрямую на выбранный пользователем сервер (по умолчанию — Groq API) и немедленно удаляются из оперативной памяти после получения распознанного текста. Локальные аудиофайлы на жестком диске не сохраняются.

2.3. Сбор персональных данных: Ни приложение RusEn, ни веб-сайт rusen.winserv.space не осуществляют сбор, систематизацию, накопление, хранение или передачу третьим лицам персональных данных физических лиц по смыслу Федерального закона РФ № 152-ФЗ «О персональных данных».

2.4. Логирование ошибок: Локальный файл rusen.log формируется исключительно на компьютере пользователя и содержит только системную техническую диагностику (наименования аудиоустройств, статусы подключения к API, коды ошибок). Пользователь может по своему желанию добровольно предоставить лог автору для диагностики багов.

3. Использование файлов Cookie на сайте

3.1. Сайт rusen.winserv.space является статической веб-страницей и не использует рекламные или трекинговые файлы cookie третьих сторон.

3.2. Технические файлы cookie или данные локального хранилища браузера (LocalStorage) могут использоваться исключительно для сохранения вашего согласия с настоящим уведомлением и корректной работы интерактивных демонстраций страницы.

4. Взаимодействие со сторонними сервисами (Groq Inc.)

4.1. При использовании облачного режима голосового ввода пользователь самостоятельно регистрирует и использует собственный ключ API сервиса Groq (Groq Inc.).

4.2. Использование сервиса Groq регулируется правилами и условиями компании Groq Inc. Автор программы RusEn не является представителем Groq Inc., не управляет их тарифами, квотами или доступностью их серверов.
