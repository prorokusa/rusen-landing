# RusEn Landing Page

Официальный сайт приложения **RusEn** — умного переключателя раскладки клавиатуры и голосового ввода Whisper AI для Windows 10/11.

🌐 Домен: [https://rusen.winserv.space](https://rusen.winserv.space)

## Стек
- HTML5, CSS3, Tailwind CSS
- Vanilla JS (интерактивный симулятор опечаток и визуализатор Whisper AI)
- Шрифты: Plus Jakarta Sans, Outfit, JetBrains Mono
- Деплой: Docker Nginx + Traefik v3 + Let's Encrypt на VPS `winserv.space`
